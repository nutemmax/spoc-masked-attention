Important variables / notation
------------------------------

The main quantities are:

- \(d\): data dimension.
- \(T\): sequence length, usually \(T=5\).
- \(\kappa^\star = r^\star/d\): teacher rank ratio.
- \(n_{\mathrm{train}}\): number of unique training samples.
- \(S^\star\): teacher matrix.
- \(S\): learned student matrix.
- \(\cos(S,S^\star)\): cosine similarity / teacher-recovery metric.
- \(R_{\mathrm{pop}}\): population risk / generalisation error.
- \(n_{\mathrm{cross}}\): first sample size where cosine similarity crosses a baseline.

Important caveat:

For masking schemes with multiple masked views per unique sample, such as `maskall` and `maskrandom_k2` / `maskmulti_k2`, the reported \(n_{\mathrm{train}}\) and \(n_{\mathrm{cross}}\) are in terms of unique underlying samples, not expanded masked views. Thus the main plots answer: “how many independent samples are needed?” If discussing fairness across masking schemes, mention that multi-mask schemes receive more masked reconstruction constraints per sample. A possible masked-view count would be \(m n_{\mathrm{cross}}\), with \(m=2\) for two-mask schemes and \(m=T\) for `maskall`, but this is not the main normalization unless explicitly plotted.

Important report narrative
--------------------------

The report should not introduce new architectures now. The final story should be:

1. We first tried simpler fixed-covariance settings, but attention did not show a meaningful advantage because the structure was too simple.

2. We then introduced a teacher-attention data model where the sample covariance is generated through a hidden teacher matrix \(S^\star\).

3. The student is trained through masked reconstruction and evaluated by:
   - training loss,
   - population risk,
   - cosine similarity \(\cos(S,S^\star)\).

4. The main empirical question is whether the student recovers \(S^\star\), and at what sample scale.

5. The cosine plots suggest that recovery occurs at a scale closer to \(d^2\) than to \(d\).

6. Crossing-threshold plots quantify this by measuring \(n_{\mathrm{cross}}\), the first sample size where the learned cosine similarity crosses a baseline.

7. Finally, population-risk plots validate that teacher recovery is functionally meaningful:
   higher \(\cos(S,S^\star)\) is generally associated with lower \(R_{\mathrm{pop}}\).

8. The relation is not perfectly deterministic. This is expected because two matrices can have different Frobenius/cosine alignment while inducing similar attention or reconstruction behavior.

Suggested wording for the generalisation validation section
----------------------------------------------------------

“In addition to measuring teacher recovery at the parameter level, we evaluate whether the recovery metric is functionally meaningful. For each masking scheme, we compare the cosine similarity \(\cos(S,S^\star)\) with the population risk \(R_{\mathrm{pop}}\). The resulting trajectories show that, in most regimes, increasing alignment with the teacher is associated with decreasing population risk. This supports the use of cosine similarity as a meaningful proxy for recovery. The relation is not expected to be exactly one-to-one, since the reconstruction objective depends on the induced attention maps rather than directly on the Frobenius alignment between \(S\) and \(S^\star\).”

Suggested wording for the crossing threshold definition
-------------------------------------------------------

“We define \(n_{\mathrm{cross}}\) as the smallest value of \(n_{\mathrm{train}}\) for which the learned cosine similarity exceeds a chosen baseline. Unless stated otherwise, \(n_{\mathrm{train}}\) denotes the number of unique underlying training samples. For masking schemes that generate multiple masked views per sample, this does not count each masked view as an independent sample.”
